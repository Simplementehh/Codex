LAS REGLAS CABEN EN UNA TARJETA

Menos guion.
Más conversación.

  1. Abre la caja y saca una tarjeta.
  2. Tócala para darle vuelta y hazle la pregunta a quien está contigo.
  3. Escucha, conversen y cambien de turno para sacar otra.

¿No les tinca una pregunta? Pásenla. Todas las preguntas van mezcladas: unas para pensar y otras para reír. No hay puntajes ni respuestas correctas.

Las tarjetas no se repiten hasta terminar el mazo. Tu avance se guarda en este navegador cuando el almacenamiento está disponible.
